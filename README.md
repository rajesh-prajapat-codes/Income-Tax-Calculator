# Income Tax Calculator

A modern and responsive Income Tax Calculator built using **HTML, CSS, and JavaScript**.

## Features

- Modern UI Design
- Glassmorphism Effect
- Responsive Layout
- Real-time Tax Calculation
- Smooth Hover Effects
- Beginner Friendly Project

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Tax Slabs Used

| Income Range | Tax Rate |
|---|---|
| Below ₹12,00,000 | 0% |
| ₹12,00,001 - ₹16,00,000 | 15% |
| ₹16,00,001 - ₹20,00,000 | 20% |
| ₹20,00,001 - ₹24,00,000 | 25% |
| Above ₹24,00,000 | 30% |
